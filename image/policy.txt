# BreathGuard RT - security policy (layer 2). Source: what secpolgenerate observed with the whole system running in
# open mode (--secpol=open): boot, ventilation, operator commands through the HMI and /dev/ventilator, and restarts of
# the HMI and the controller. Nothing below was written by hand except this header. The rules for our types (bg_*)
# come first in the rules section; image/README.md explains them. image/data_files.custom RESTRICTS our types to
# these rules.
# This represents a policy that should allow a system to perform all the
# same actions as have been observed since the policy generator has been
# running.

# There have been one or more uses of secpol_resmgr_attach() that can have
# permissions set for them in the policy. See the mount_point entries at
# the end.
